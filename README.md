### Implementation
For Software:
# Installation
1. Create the project
mkdir textile-ai
cd textile-ai

mkdir backend
npm create vite@latest frontend -- --template react

2. Backend installation
cd backend

python -m venv venv

Windows
venv\Scripts\activate

macOS / Linux
source venv/bin/activate

Install the Python libraries:

pip install fastapi uvicorn opencv-python numpy pillow python-multipart

If you're actually using AI/ML:

pip install tensorflow

or, if you're using PyTorch:

pip install torch torchvision

You can save the dependencies:

pip freeze > requirements.txt

# Run
4. Run the backend
From the backend directory, with the virtual environment activated:

uvicorn main:app --reload

Your API should then be available at:

http://127.0.0.1:8000

FastAPI's interactive API documentation will normally be at:

http://127.0.0.1:8000/docs

5. Run the frontend
In another terminal:

cd textile-ai/frontend
npm run dev

Vite will show the local address, typically:

http://localhost:5173

⚡ Quick Run
Once everything is installed, you generally need two terminals:

Terminal 1 — Backend

cd textile-ai/backend
venv\Scripts\activate
uvicorn main:app --reload

Terminal 2 — Frontend

cd textile-ai/frontend
npm run dev
